# どこに渡せば開発に届くか（2026-11 時点の整理）

## なぜ跳ね返されたか

Xiaomi Japan CS の回答は「キャリアモデル（SoftBank 販売）なので販売元へ」だった。
これは**販売チャネルごとのアフターサービス方針**によるもので、内容を読んだ上での判断ではない。
CS の窓口は保証・修理が担当で、**開発（HyperOS / AI サービス）への転送経路を持っていない**。
したがって、同じ窓口に技術情報を送り直しても同じ文面が返る可能性が高い。

一方で、不具合の本体は Xiaomi 製のシステムコンポーネント：

- `com.xiaomi.aiservice`（Taiyi / AI リソース管理）
- `com.android.providers.downloads`（HyperOS の DownloadProvider）

キャリアモデルでもこの 2 つは Xiaomi が供給しており、SoftBank 側では修正できない。
**「保証の話ではない」と切り口を変えるのが要点。**

---

## 届く順に並べた窓口

### 1. 端末内「サービスとフィードバック」 ─ 最有力

- 設定の一番下、またはアプリ一覧の「サービスとフィードバック」
- 「フィードバック」→ カテゴリ（システム / アプリ）→ 説明を入力 → **ログを有効化**して送信
- 端末のログが添付され、**開発側に直接届く**唯一の公式経路
- キャリアモデルかどうかは関係ない（ROM 内のアプリなので）
- 注意: 反応が返らないこともある（他ユーザーの報告でも「送ったが音沙汰なし」）。単独では弱い

### 2. Xiaomi Community（英語） ─ 公開かつ公式が目にする

- https://c.mi.com/global/ / https://new.c.mi.com/global/
- HyperOS のフィードバック板に投稿。海外モデレーターが「フィードバックアプリで送ってください」と
  案内する運用なので、**両方やるのが正解**
- 公開なので放置されにくい。同じ症状の人が集まると優先度が上がる
- 投稿文: `03_community_post_en.md`

### 3. X（@XiaomiSupport / @XiaomiJapan）

- 英語は @XiaomiSupport、日本語は @XiaomiJapan
- DM は基本返らない。**公開リプライで「送付先を教えて」と聞く**形が反応を得やすい
- 投稿文: `04_x_posts.md`（スレッド構成つき）

### 4. SoftBank ─ 記録と転送のため

- 「故障相談ではない／保証は不要／技術窓口へ転送してほしい」と明示する
- 販売元としてメーカーへ上げる経路はあるので、**技術窓口に届けば一番早い可能性もある**
- 文面: `02_softbank_ja.txt`

### 5. Xiaomi Japan CS（再返信）

- 期待値は低いが、**チケットに「エスカレーション不可」の記録を残す**意味がある
- 文面: `01_xiaomi_reply_ja.txt`
- 「転送できないなら、できないと明示してください」と書くのがコツ（定型文を崩す）

## 文面のコツ

1. **最初の 2 行で「保証・修理ではない」と宣言する**
   これを書かないと「初期化してください」で終わる
2. **コンポーネント名を先に出す**
   `com.xiaomi.aiservice` / `com.android.providers.downloads` を冒頭に置くと、
   ユーザーの感想ではなく**技術的な不具合報告**として読まれる
3. **数字を 3 つだけ**（11.7 GB / 162 個 / 設定 OFF でも発生）
4. **してほしいことを 1 つに絞る**（技術部門へ転送してほしい）
5. 添付は PDF 1 通（`taiyi_report_ja.pdf`）。X だけ画像（`05_screenshot_model_settings.png`）

## 補足
